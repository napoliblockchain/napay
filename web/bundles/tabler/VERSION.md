- Tabler core 1.6.1, CSS originale del pacchetto npm `@tabler/core`.
- Shasum archivio npm: `eeca2b82f8be5200d97696aaad125a69fe0a57a8`.
- Licenza Tabler MIT: `LICENSE`.
- Bootstrap JavaScript 5.3.8: `bootstrap.bundle.min.js` originale dal pacchetto
  `twbs/bootstrap`; licenza MIT in `BOOTSTRAP-LICENSE`.

  form, modali, menu e grafo asset prima del rilascio.
